# Парсер статей с Habr

Простой парсер, который собирает статьи с главной страницы [Habr](https://habr.com/ru/articles/) и фильтрует их по ключевым словам.

## Возможности

- Парсинг заголовков, ссылок и дат статей
- Поиск по ключевым словам: `дизайн`, `фото`, `web`, `python`
- Автоматическое форматирование дат в удобочитаемый вид (например: `05.04.2025 14:22`)
- Сохранение результатов в `articles.json`

## Требования

- Python 3.8+
- Установленные зависимости (см. ниже)

## Установка

1. Установите зависимости:
    `bash pip install requests beautifulsoup4 fake-headers`
2. Запустите скрипт:
    `bash python main.py`

## Результат

После выполнения в корне появится файл `articles.json` с найденными статьями.
